# 功能：数据库表结构与初始化（Database）

## 定位
PostgreSQL 空库建表 + 视图软删除 + 表/字段注释 + 3 人种子数据（幂等）。

## 涉及文件
- `sql/02_schema.sql` — 12 张表 DDL（含通用基础字段、CHECK/索引/唯一约束）
- `sql/03_views.sql` — `v_` 软删除视图 + app_ro/app_rw 授权
- `sql/04_comments.sql` — 表/字段 COMMENT
- `scripts/setup_db.py` — 一次性初始化（建角色 + 建表 + 建视图 + 注释 + 种子）

## 核心逻辑
1. 建运行时角色 `app_ro`（业务只读）/ `app_rw`（checkpointer + 会话读写）。
2. 建 12 张表：department / employee / attendance_record / leave_record / overtime_record / business_trip / makeup_card / attendance_statistics / holiday_calendar / sys_user / role / user_role / chat_session。
3. 建 `v_` 视图（内固化 `is_deleted=FALSE AND is_enabled=TRUE`），业务只查视图。
4. 灌 3 名员工 + 1 管理员账号（动态日期），覆盖迟到/早退/缺卡/补卡/请假/加班/出差/调休/恶意 reason 对抗用例。

## 关键设计点
- **所有表带通用基础字段**；表/字段全部写 COMMENT（维护 + LLM 语义）。
- **幂等**：`seed()` 先 `TRUNCATE ... RESTART IDENTITY CASCADE` 再灌。
- `app_rw` 需 `GRANT USAGE ON SEQUENCE chat_session_id_seq`（SERIAL 插入必需）。
- 种子日期按"运行当月"动态生成，与 `{today}` 注入对齐。

## 依赖
- `app/config.py`（PG 连接 + 角色）、`psycopg`。
