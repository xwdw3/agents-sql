# 功能：记忆与指代消解（Memory）

## 定位
多轮可追问：保留近期上下文 + 用 LLM 把"他/上周"等指代替换为具体对象（`resolved_question`），供下游节点消费。

## 涉及文件
- `app/memory.py` — `update_memory()`（滑动窗口截断）、`format_history()`
- `app/graph/nodes.py` — `resolve_node`
- `app/prompts.py` — `RESOLVE_PROMPT`
- `app/schemas.py` — `ResolveResult`

## 核心逻辑
1. `resolve_node`：有历史时，LLM 结构化输出 `{resolved_question}`（把"他呢"→"张三早退几次"）；无历史原样返回。
2. 下游 `route/policy/schema_select/sql_generate/answer` 统一用 `_q(state)`（`current_question or resolved_question or user_input`）。
3. `memory_node`：只做滑动窗口截断（保留最近 8 条），追加本轮 user/assistant 消息。
4. 持久化：`PostgresSaver` 以 `thread_id` 存整个图状态（含 messages）。

## 关键设计点
- **不用硬编码姓名/时间词做子串匹配**（会与库脱节、无法处理代词、易误匹配）；改用 LLM 结构化指代消解。
- 多步执行时用 `current_question` 隔离每个子问题，避免串扰。

## 依赖
- `app/llm.py`、`app/graph/state.py`、`langgraph-checkpoint-postgres`。
