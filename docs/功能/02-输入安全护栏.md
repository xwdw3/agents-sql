# 功能：输入安全护栏（Input Guard）

## 定位
在用户问题进入模型前做危险内容评估，拦截 prompt 注入 / 有害内容 / 越权试探 / 敏感索取。

## 涉及文件
- `app/safety/input_guard.py` — `check_input()`
- `app/prompts.py` — `GUARD_PROMPT`
- `app/schemas.py` — `GuardResult`

## 核心逻辑
1. **规则快筛（确定性，零成本）**：正则黑名单命中（"忽略指令""你现在是""drop table"、身份证/银行卡/密码等）直接拒绝。
2. 长度上限（1000 字符）。
3. **LLM 精判（结构化）**：输出 `{is_safe, category, reason}`，category ∈ `normal / prompt_injection / harmful / off_topic / sensitive_request`；非 `normal` 拒绝。

## 关键设计点
- 两级互补：规则防"已知攻击"，LLM 防"语义变体"。
- 拒绝时不携带任何检索结果，只回统一拒绝话术。

## 依赖
- `app/llm.py`（invoke_structured）、`app/schemas.py`。
