# 功能：会话管理（Session）

## 定位
持久化"谁有哪些会话"：`chat_session` 表做 `user_id ↔ thread_id` 映射，配合 LangGraph checkpointer 实现多轮对话与历史回放。

## 涉及文件
- `app/session.py` — `create_session()` / `list_sessions()` / `get_session()`
- `app/db/engine.py` — `rw_engine()`（app_rw 连接，会话读写）
- `sql/02_schema.sql` — `chat_session` 表
- `sql/03_views.sql` — app_rw 授权（含序列 `chat_session_id_seq` USAGE）
- `main.py` — `/api/sessions`、`/api/sessions/{thread_id}`、`/api/chat` 里的会话建立/归属校验

## 核心逻辑
1. `/api/chat` 无 `thread_id` → 生成 uuid → `create_session(user_id, thread_id, title=首问前30字)`。
2. 有 `thread_id` → `get_session(user_id, thread_id)` 校验归属，越权返回 403。
3. `/api/sessions` → `list_sessions(user_id)` 返回该用户会话列表。
4. `/api/sessions/{thread_id}` → 校验归属后，从 `graph.get_state` 读历史消息回放。

## 关键设计点
- 两层持久化：`chat_session`（会话元数据）+ `PostgresSaver` checkpoint（对话状态/记忆），都落 PG。
- 首次对话经 SSE `session` 事件回传 `thread_id`，前端捕获后维持会话。

## 依赖
