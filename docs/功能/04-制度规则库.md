# 功能：制度规则库（Rule Store）

## 定位
把《考勤管理制度》**拆分存储为"类型 + 具体规则"**，按问题动态路由只取相关规则，避免全量注入互相干扰；罚款等金额用确定性函数计算。

## 涉及文件
- `app/rules/rule_store.py` — `RULES` / `RULE_TYPE_LIST` / `select_by_keywords()` / `get_rules()`
- `app/rules/fines.py` — `late_or_early_fine()` / `overtime_pay()` / `makeup_fine()`

## 核心逻辑
1. 规则按 `rule_type`（工作时间/加班认定/周日加班/法定节假日加班/打卡/补卡/迟到/早退/请假/旷工/出差/周日及法定节假日 + **裁定**）拆分。
2. 动态路由：`route_node` 输出 `rule_types`（LLM）+ 关键词快匹配取并集 → `get_rules(rule_types)` 取对应规则 + 裁定。
3. 金额计算在 `fines.py` 确定性实现（不让 LLM 写 `CASE WHEN`）。

## 关键设计点
- **单源化**：分档/口径作为"裁定"类型条目唯一维护，提示只引用不复制。
- 30 分钟边界裁定：`m≥30 按旷工`（不计迟到/早退次数）。
- 调休口径：`8 小时 = 1 天，按月净额`。
- 未来迭代：规则单元上叠加向量语义 + BM25 混合召回（`HybridRetriever`）。

## 依赖
- `app/llm.py`（路由时的结构化分类）、`app/graph/nodes.py`（调用方）。
